# MLA03 – Reinforcement Learning Assignment 3

## Project Title
**Implementation of Reinforcement Learning Algorithms**

## Description
This project demonstrates the implementation of important Reinforcement Learning concepts and algorithms using Python. It covers reward calculation, Monte Carlo methods, Actor-Critic learning, Proximal Policy Optimization (PPO), and Deep Deterministic Policy Gradient (DDPG).

## Technologies Used
- Python 3
- NumPy
- VS Code

## Project Structure

```text
Assignment 3 RL/
│
├── q1_calculate_reward.py
├── q2_calculate_returns.py
├── q3_actor_critic.py
├── q4_ppo.py
├── q5_ddpg_soft_update.py
│
└── README.md
```

## Tasks Implemented

### Task 1 – Reward Calculation
- Calculates rewards for different actions.
- Provides positive rewards for collecting treasure.
- Applies negative rewards for encountering enemies.
- Provides rewards for reaching the exit.

### Task 2 – Monte Carlo Returns
- Implements discounted return calculation.
- Uses the discount factor (gamma).
- Calculates returns from episode rewards.

### Task 3 – Actor-Critic Algorithm
- Calculates the TD target.
- Calculates TD error.
- Calculates the advantage function.

### Task 4 – Proximal Policy Optimization (PPO)
- Calculates the probability ratio.
- Implements the clipped objective.
- Demonstrates PPO policy updates.

### Task 5 – Deep Deterministic Policy Gradient (DDPG)
- Implements soft updates of target network weights.
- Uses the parameter tau.
- Demonstrates the update of target weights.
