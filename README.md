## Project Description
This project studies Reinforcement Learning and Markov Decision Processes for adaptive smart traffic signal management. It covers RL concepts, MDP formulation, Bellman equations, Bandit algorithms and experimental evaluation.

## Folder Structure
- Task01 – RL Framework and Problem Analysis
- Task02 – Markov Decision Process
- Task03 – Policies, Value Functions and Bellman Equations
- Task04 – Exploration, Exploitation and Bandit Algorithms
- Task05 – Integrated Project Design and Evaluation

## Software Requirements
- Python 3
- NumPy

TensorFlow and Keras are discussed as optional libraries and are not required for the baseline programs.

Run the programs from their respective folders:


## Experimental Results
The Task05 simulation compared Fixed-time, Greedy Bandit and Epsilon-greedy Bandit methods.

- Fixed-time average waiting time: 29.91
- Greedy Bandit average waiting time: 17.94
- Epsilon-greedy average waiting time: 18.46
